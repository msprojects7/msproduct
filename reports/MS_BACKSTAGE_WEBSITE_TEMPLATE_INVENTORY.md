# MS BACKSTAGE — WEBSITE TEMPLATE INVENTORY

## 1. Overview
MS Backstage delivers 10 production-grade, responsive event website templates defined in `lib/website/templates.ts`. Each preset specifies unique palette configurations, typography selections, hero layout modes, card surface styling, and default section prioritization.

## 3. Template Feature Breakdown

### 1. Modern Conference
- **Ideal For:** Annual corporate conferences, global industry summits, user conferences.
- **Visual Design:** Vibrant gradient banners, floating card badges, interactive session filters.
- **Section Priority:** About → Passes → Keynote Faculty → Multi-Track Agenda → Partners → Expo → Venue.

### 2. Technology Summit
- **Ideal For:** Developer conferences, AI symposiums, cybersecurity conventions, hackathons.
- **Visual Design:** High-contrast dark cyberpunk ambiance, monospaced badges, code-accented cards.
- **Section Priority:** Developer Passes → Tech Speakers → Code Tracks → Mission → Tooling Sponsors → Terminal Venue.

### 3. Business & Leadership
- **Ideal For:** World economic forums, C-suite roundtables, institutional investor summits.
- **Visual Design:** Formal serif typography, navy and gold borders, prestigious patron recognition.
- **Section Priority:** Executive Overview → Faculty & Chairs → Plenary Proceedings → Delegate Passes → Corporate Patrons → Palace Venue.

### 4. Startup & Innovation
- **Ideal For:** Demo Days, accelerator pitch showcases, founder summits, venture networking.
- **Visual Design:** High-energy coral and orange highlights, pitch-deck card ratios, prominent ticket CTAs.
- **Section Priority:** Passes → Demo Day Format → Judges & Angels → Pitch Schedule → Ecosystem Partners → Startup Alley → Campus Venue.

### 5. Academic & Education
- **Ideal For:** Medical congresses, peer-reviewed scientific colloquiums, university symposiums.
- **Visual Design:** Ivy-league crimson and navy styling, formal abstract presentation blocks.
- **Section Priority:** Call for Abstracts → Scientific Program → Faculty → Delegate Registration → Benefactors → Equipment Expo → Hall Venue.

### 6. Creative & Design
- **Ideal For:** Design weeks, animation festivals, typography congresses, spatial computing conferences.
- **Visual Design:** Electric pink and violet aurora glows, asymmetric grid layouts, immersive dark canvas.
- **Section Priority:** Visionary Creators → Studio Workshops → Festival Wristbands → Manifesto → Interactive Installations → Design Studios → Warehouse Venue.

### 7. Expo & Exhibition
- **Ideal For:** High-footfall trade marts, auto expos, machinery expos, buyer-seller conventions.
- **Visual Design:** Trade show emerald styling, heavy exhibitor directory prominence, bold registration banner.
- **Section Priority:** Exhibitor Directory & Floorplan → Trade Visitor Badges → Floor Highlights → Seminars → Panelists → Official Trade Partners → Convention Gates.

### 8. Workshop & Training
- **Ideal For:** Developer bootcamps, certified masterclasses, executive training retreats.
- **Visual Design:** Progressive teal learning roadmap, prerequisites highlights, mentor spotlights.
- **Section Priority:** Curriculum & Prerequisites → Lab Modules → Instructors & Mentors → Enrollment Seats → Tooling Sponsors → Facility Venue.

### 9. Luxury & Premium
- **Ideal For:** Private wealth summits, luxury brand showcases, invitation-only galas.
- **Visual Design:** Onyx black and champagne gold, understated typography, discreet VIP tiering.
- **Section Priority:** Private Invitation → Patron Tables & VIP Passes → Honorary Guests → Evening Itinerary → Maison Benefactors → Private Residence Venue.

### 10. Minimal & Elegant
- **Ideal For:** Contemporary architecture biennials, literary forums, Swiss graphic design events.
- **Visual Design:** Monochrome black and white, razor-sharp rules, high legibility, ample whitespace.
- **Section Priority:** Focus & Synopsis → Colloquium Schedule → Speakers & Curators → Symposium Registration → Publishing Partners → Gallery & Directions.
